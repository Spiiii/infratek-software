## Dependency audit

Command: `npm audit --json`

Result: failed security gate.

| Severity | Count |
|---|---:|
| Critical | 1 |
| High | 6 |
| Moderate | 1 |
| Total vulnerable dependency groups | 8 |

Important direct findings:

- Next.js `15.5.20` is affected by multiple advisories. The audit reports fixes available and includes critical issues affecting versions below `15.5.24`.
- Direct PostCSS `8.5.16` is affected by published path traversal/information disclosure advisories; a fixed version is available.

Transitive findings include vulnerable versions of `baseline-browser-mapping`, `brace-expansion`, `browserslist`, `js-yaml`, `nanoid`, and `sharp`.

The compatibility spikes must not be accepted solely because they build. Each selected dependency set must also pass the agreed security gate or have every remaining finding documented with exposure and mitigation.

## Confirmed functional gaps

- Contact UI bypasses the internal Resend API and submits to Formspree.
- AI Readiness lead capture only logs to the browser console.
- Download Center uses an alert instead of real downloadable assets.

- Animated counters initially render zero.
- `/blog` is a full Client Component.
- JSON-LD and complete canonical/Open Graph coverage are not present.
- Several UI components and direct dependencies are not referenced by active application code.

## Spike acceptance checklist

Each Next.js/Payload spike must record:

- Exact pinned versions for Next.js, React, React DOM, eslint-config-next, Payload and all `@payloadcms/*` packages.
- Clean dependency installation and stable lockfile.
- No invalid peer dependencies or duplicate React installation.
- Passing typecheck and ESLint.
- Passing production build.
- Security audit result and disposition of every high/critical finding.
- Existing frontend smoke check.
- Payload `/admin` startup.
- Postgres connection.
- A minimal migration.
- Read/write of a sample collection through the Local API.
- Preview deployment result.
- Compatibility of `experimental.optimizePackageImports`.
- Final recommendation and rejected-alternative rationale.
