## P5.4 input boundary

Decision policy nhận trực tiếp `RetrievalResult` của P5.4 gồm `status`, `sources` và `diagnostics`. Policy không định nghĩa lại retrieval contract, không re-query, re-rank, re-sort hoặc tái tạo source.

Nguồn được giữ nguyên từ `retrievalResult.sources`, tối đa `S1...S6`. Vector distance, vector similarity, FTS score và RRF score không tham gia quyết định pre-calibration.

## AnswerDecision

Các trạng thái:

- `ANSWER`: dành cho calibrated policy tương lai, mang sources và policy version;
- `NO_CONTEXT`: structural hybrid zero, reason `STRUCTURAL_ZERO`;
- `DEPENDENCY_FALLBACK`: dependency không dùng được hoặc runtime state không hợp lệ, dùng reason đã sanitize;
- `CALIBRATION_REQUIRED`: có candidates hoặc degraded zero nhưng chưa được phép kết luận relevance.

Mọi decision đều mang `policyVersion`. `NO_CONTEXT` và `DEPENDENCY_FALLBACK` không tạo sources giả.

## Default pre-calibration policy

Policy version: `pre-calibration-p5.5-v1`.

| Retrieval status | Decision |
| --- | --- |
| `HYBRID / HAS_CANDIDATES / UN_CALIBRATED` | `CALIBRATION_REQUIRED` |
| `FTS_ONLY / HAS_CANDIDATES / UN_CALIBRATED` | `CALIBRATION_REQUIRED` |
| `VECTOR_ONLY / HAS_CANDIDATES / UN_CALIBRATED` | `CALIBRATION_REQUIRED` |
| `HYBRID / NO_CANDIDATES / NO_CONTEXT` | `NO_CONTEXT / STRUCTURAL_ZERO` |
| `FTS_ONLY / NO_CANDIDATES / UN_CALIBRATED` | `CALIBRATION_REQUIRED` |
| `VECTOR_ONLY / NO_CANDIDATES / UN_CALIBRATED` | `CALIBRATION_REQUIRED` |
| `UNAVAILABLE / UNKNOWN / UNAVAILABLE` | `DEPENDENCY_FALLBACK / RETRIEVAL_UNAVAILABLE` |

Default policy không có nhánh trả `ANSWER`. Kể cả retrieval status `ACCEPTED` xuất hiện trước khi calibrated policy được inject, pre-calibration policy vẫn trả `CALIBRATION_REQUIRED`.

`CALIBRATION_REQUIRED` là trạng thái production tạm thời trước P5.7. Đây không phải relevance rejection. Nó có nghĩa production có candidates nhưng chưa được ủy quyền phân loại chúng là answerable.

## P5.7 policy seam

P5.5-A không tạo numeric similarity, distance, FTS hoặc RRF threshold và không tái sử dụng `UN-CALIBRATED` như thể đó là calibrated policy version.

## P5.5-B — Context và citation grounding

Context builder nhận trực tiếp `SelectedSource[]`, giữ nguyên thứ tự và labels, giới hạn tối đa sáu source. Wrapper tin cậy tiếp tục là `<CONTEXT_DATA>` trong system prompt; builder tạo phần thân từ whitelist `label`, `title`, `headingPath`, public `url` và `content`.

Dữ liệu nguồn được serialize thành từng field một dòng. Backslash, newline, angle bracket và square bracket trong dữ liệu CMS được chuyển thành literal escape. Vì vậy dữ liệu không thể đóng wrapper, thêm metadata line hoặc tạo trusted `[S#]` block. Đây là phân tách cấu trúc, không phải tuyên bố miễn nhiễm prompt injection ở cấp model.

Citation validator chỉ chấp nhận canonical `[S1]...[S6]` thuộc labels thực sự đã đưa vào context. Thiếu citation, citation ngoài context, source-like citation malformed hoặc output trộn valid/invalid đều bị reject toàn bộ; không repair provider output. Exact `KHONG_CO_THONG_TIN` được chấp nhận sau trim whitespace và không cần citation. Sentinel kèm punctuation, citation, quote hoặc prose bị reject.

Public-source mapper chỉ lấy metadata URL do server sở hữu từ selected sources thực sự được cite, deduplicate citation và giữ thứ tự context. Model-generated URL không được đọc hoặc tin cậy; diagnostics và content không được expose qua mapper này.

## P5.5-D — Security boundary

Ngày triển khai: 2026-10-06.

### OWNER-APPROVED DECISIONS

| Quyết định | Implementation |
| --- | --- |
| D-01 | Session TTL khóa ở đúng 604.800 giây (7 ngày); hết hạn phải Turnstile lại. |
| D-02 | `CHAT_SESSION_SIGNING_SECRET` và `CHAT_IP_HMAC_SECRET` là hai secret riêng, không fallback/reuse secret khác. |
| D-03 | `TURNSTILE_VERIFY_TIMEOUT_MS` mặc định 5.000 ms. |
| D-04 | New/invalid/expired session fail closed khi token thiếu, invalid, timeout hoặc provider unavailable; valid session skip Turnstile. |
| D-05 | Upstash error/malformed response fail closed thành `DEPENDENCY_UNAVAILABLE`; không có in-memory fallback production. |
| D-06 | Minute dùng sliding 60 giây, daily dùng UTC boundary, session counter tồn tại đúng tới session expiry. |
| D-07 | Production `ClientIpResolver` cố ý trả `DEPLOYMENT_VERIFICATION_REQUIRED`; chưa tin `x-forwarded-for`/`x-real-ip` trước Preview verification. |
| D-08 | Minute limit → `RETRY_LATER`; các cap dài hạn → `CONTACT_FALLBACK`; dependency failure → `SERVICE_FALLBACK_WITH_CONTACT`. Contact lấy từ canonical `src/data/company.ts`. |

### SOURCE-COMPATIBLE IMPLEMENTATION

- HMAC-SHA-256 versioned session token, random opaque 32-byte ID và timing-safe signature comparison;
- cookie contract: HttpOnly, Secure ở production, SameSite Lax, Path `/`, MaxAge/expiry 7 ngày;
- Turnstile Siteverify adapter gửi tối thiểu secret/response, tối đa một call, không retry, timeout/error được sanitize;
- IP limiter key dùng keyed HMAC-SHA-256 với secret riêng;
- `@upstash/redis` là dependency duy nhất được thêm; một Lua `EVAL` atomic kiểm tra và consume cả bốn dimension, SDK retry bị tắt để không lặp một consume request;
- namespaced Redis keys không chứa raw IP hoặc secret; retry metadata chỉ được trả khi reset time xác định;
- reusable security orchestration dừng trước limiter nếu Turnstile fail và dừng trước retrieval/Gemini nếu limiter fail;
- deterministic provider-free tests dùng fake clock/dependencies; Turnstile, Upstash, Gemini và database live calls đều bằng 0.

### Route và HTTP contract

- Route duy nhất: `POST /api/chat`; Next.js tự xử lý method khác bằng `405`.
- Body strict chỉ chấp nhận `question` và optional `turnstileToken`; question trim, không rỗng và tối đa 500 ký tự. Client không được gửi conversation/session ownership, history, sources, model, prompt hoặc policy inputs.
- HTTP mapping hẹp: `200` cho safe domain outcomes; `400` invalid/attack; `403` verification; `429` rate limit; `503` dependency/persistence/D-07 gate. JSON `status` là contract authoritative.
- Response public chỉ gồm các field được allow-list. Cookie signed không đi vào JSON; sources của ANSWER chỉ lấy từ server-owned cited-source mapper.

### Ordered pipeline

Validation → gated trusted-IP resolver → signed session/Turnstile → Upstash limiter → coarse filter → server-owned active conversation lookup → tối đa 6 history messages → multi-turn preparation tối đa 2 completed turns → P5.4 retrieval → decision policy → generation chỉ ở ANSWER → citation/protected-output validation → D-11/D-12/D-13 persistence → public mapping → signed cookie response.

Active conversation được tìm bằng `session_id` lấy từ signed session, trạng thái active và chưa hết hạn. Client `conversationId` bị schema strict từ chối. Schema P5.2 hiện tại đủ cho query này nên F1 không migration hoặc đổi schema. Retention vẫn 30 ngày; cleanup cron thuộc Phase 6.

### Security và calibration gates

D-07 tiếp tục là `DEPLOYMENT_VERIFICATION_REQUIRED`. Production resolver không tin `x-forwarded-for`, `x-real-ip` hoặc `x-vercel-forwarded-for`; route production vì thế fail closed trước Turnstile/Upstash/retrieval. Provider-free route tests chỉ inject fake trusted resolver, không tạo public/env/query bypass.

P5.7 tiếp tục `UN-CALIBRATED`. Production dùng `PreCalibrationDecisionPolicy`, không có nhánh ANSWER. `CALIBRATION_REQUIRED` gọi Gemini 0, conversation write 0 và unanswered write 0. ANSWER tests dùng injected calibrated fixture chỉ để xác minh integration seam.

### Persistence outcomes

- ANSWER: redacted user + safe assistant + cited server sources; write failure → `DEPENDENCY_FALLBACK`.
- NO_CONTEXT / exact NO_ANSWER: redacted user + deterministic fallback, sau đó best-effort unanswered upsert; conversation write failure fail closed, unanswered failure không thay response.
- Unsupported output: reject toàn bộ output, persist user-only event với internal review flags, public `SAFE_FALLBACK`; write failure fail closed.
- Citation-invalid/provider/retrieval failures: không conversation write và không unanswered write.
