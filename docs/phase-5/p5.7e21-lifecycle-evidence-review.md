## Lifecycle root cause và fix

Sau retry thành công, `getPayload()` đã mở database pool nhưng CLI không gọi lifecycle cleanup nên event loop tiếp tục giữ process. Fix thêm managed executor và gọi `payload.destroy()` trong `finally`.

- Success: evidence được ghi xong trước cleanup.
- Error: cleanup vẫn chạy đúng một lần.
- Payload chưa khởi tạo: cleanup no-op.
- Không dùng forced process termination.
- Không thay đổi production Payload/API, retrieval algorithm hoặc budget guard.
